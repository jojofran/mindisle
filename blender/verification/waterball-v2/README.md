# Waterball v2 主流程验证

这一步把静态视觉目标接入真实冥想流程，目的不是把一张图当成最终动画，而是先固定可复用的构图、命中区域和状态边界。

验证入口：`waterball.html` 或主流程 `index.html`。本地预览使用 `python3 -m http.server 8765`，然后打开 `http://127.0.0.1:8765/index.html`。

## 已验证

- `我的岛 → 开始一段时间 → 下一步 → 进入这段时间`：状态球进入 moving，倒计时开始递减。
- 点击中央水球：视觉切到 still，按钮语义变为“开始或继续冥想”。
- still 状态等待 800ms：计时显示保持不变，说明时钟冻结。
- 点击“继续”：视觉回到 moving，计时继续递减。
- 点击“结束这段时间”并确认：进入完成页，星光增加，时间线新增一条记录。
- `profile.js` 提供固定视角下的中心、半径、body mask、node 和 flow 端点；组件把同一坐标用于绘制和命中。

## 当前边界

当前水球层是项目内 v1 烘焙目标图的裁切组合，`continuousAnimation=false`。它证明的是“视觉目标已经进入状态驱动的产品主流程”，不证明 Blender 程序化材质、Unity Shader 或移动端性能已经完成。

下一步只推进一个最大差距：用 profile 中的 body / flow / node 数据替换烘焙层，并保持上述状态读取和真实点击证据不变。
