# MindIsle 状态球视觉规格

## 文档定位

本文档描述中央状态球的产品视觉语言、状态差异、审美目标和视觉验收标准。不规定编程语言、渲染引擎、建模工具、素材格式或运行时架构。任何实现方式都必须以本文档描述的用户感受和可观察结果为验收对象。

## 产品角色

状态球是专注界面的主要视觉焦点、主要操作入口和状态反馈载体。它不是装饰性插图，也不是需要展示复杂技术的 3D 模型。用户应当通过状态球直观感知“尚未开始、正在进入、专注正在持续”之间的差异。

## 总体审美

状态球应给人安静、湿润、柔和、透明、有体积但不沉重的感受。它可以让人联想到水滴、薄雾、缓慢流动的液体和被光线穿透的柔软材质，但不能读成硬玻璃、塑料、金属、按钮、徽章或装饰图标。

视觉表达应克制：有足够的结构让球体可被理解，有足够的留白让专注不被打扰；光泽、颜色、运动和细节都服务于状态表达，不以刺激或炫技为目的。

## 状态球本体

- 球体应保持完整、圆润、连续，不能被裁切或被无关元素遮挡；
- 球体应具有透明度、厚度和内部体积感，不能只是平面色块或均匀渐变圆；
- 外轮廓应柔和但可辨识，不能是硬塑料描边，也不能因为过度模糊而失去边界；
- 外壳的明暗和光泽应随球体曲率变化，不能形成均匀完整的白色圆环；
- 内部体积应有青绿色及相邻冷色层次，并呈现深浅、透射和局部雾化；
- 内部应保留柔和的绕行明暗关系，让人感到两股水体相互包裹，但不能形成具象太极图或 Logo；
- 两个细小点位保持左上冷色、右下暖色的对角关系，点位嵌入内部体积，不能像按钮、贴纸或装饰灯珠；
- 高光应沿球体曲率或内部流层连续展开，亮度克制，不能出现孤立的大白斑或过强光晕。

## 静止状态

静止状态表达“专注尚未运动或当前保持安静”。

- 外轮廓、主体中心、体积关系和两个点位保持稳定；
- 内部主要流动和形变冻结；
- 只允许明确约定的极轻微呼吸或光泽变化；
- 内部明暗关系应收敛、安静、可辨识；
- 第一眼应读成“透明、有体积的水球”，而不是青色雾团、玻璃弹珠或纯色 UI 圆形。

## 运动状态

运动状态表达“专注正在持续”。

- 与静止状态共享主体中心、主要轮廓、尺寸和触摸范围；
- 变化主要来自内部流动层、局部光泽、柔和形变和缓慢呼吸；
- 内部流层应像水体内部的连续密度和光线变化，而不是球体外部挂着的管线、绳子或独立环带；
- 运动应连续、缓慢、可感知但不打扰专注；
- 不得通过突然跳位、闪烁、外部装饰或强烈色彩变化表达运动；
- 运动参考图中若出现与产品语义冲突的外部装饰，应记录为参考差异，不直接复制。

## 状态切换

- `still → transitioning → moving` 应保持视觉连续；
- 过渡期间球体不能突然跳位、改变触摸范围或改变整体语义；
- 过渡可以逐步增加内部流动、光泽和形变，但不应一次性出现新的外部结构；
- 状态是唯一事实来源，视觉变化只是状态的表现；
- 如果视觉实现无法可靠表达某个状态，应调整视觉实现，不得改变状态契约来迁就动画。

## 视觉禁用项

以下结果不应被视为符合状态球视觉方向：

- 灰色调试圆盘或可见的技术结构；
- 外露管线、独立环带、绳状曲线或与球体脱离的装饰；
- 网格、线框、采样纹理或明显的程序化调试痕迹；
- 硬塑料、金属、玻璃弹珠或纯色气泡感；
- 均匀青色圆、没有内部结构的雾团；
- 单条 S 形符号、太极图标或其他具象 Logo；
- 孤立的大白高光、过强 Bloom 或闪烁；
- 过大的点位、按钮感点位或脱离体积的装饰光点；
- 复杂背景、额外物件或抢过状态球注意力的效果。

## 视觉验收

静止状态必须同时满足：

1. 球体完整显示，第一眼可读为透明、有体积的水球；
2. 外壳、内部体积和绕行明暗关系都可辨识；
3. 青绿色内部层次不是均匀纯色填充；
4. 两个点位清晰、克制并保持左上冷色 / 右下暖色关系；
5. 高光不会盖过内部结构；
6. 没有视觉禁用项；
7. 缩小到缩略图后仍保留水球的主要结构和气质。

运动状态必须在静止验收通过后再判断，并额外满足：

1. 运动主要发生在球体内部；
2. 主体中心、轮廓和触摸范围稳定；
3. 运动连续、缓慢、可重复；
4. 静止和运动能够被清楚区分，但不会像两个不同产品；
5. 状态读取和真实输入结果与视觉表现一致。

## 参考图使用原则

用户当前明确指定的参考图优先于历史截图、旧原型和代理自行生成的素材。参考图中直接可见的内容与产品约束发生冲突时，应记录冲突并遵循产品约束。单张参考图无法确定的内容必须标记为推断，不得伪装成参考事实，也不得为了填补未知部分增加不必要的系统。

## 与实现无关的完成定义

视觉完成不是“有一个球”或“渲染成功”，而是状态球在静止和运动状态下都能传达正确的产品感受，并通过参考图对比、真实输入和状态读取得到证据。任何具体技术方案都可以替换，只要不改变上述体验和验收结果。
