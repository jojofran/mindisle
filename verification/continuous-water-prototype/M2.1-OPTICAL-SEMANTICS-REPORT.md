## Baseline

## Corrections

1. **Volume alpha** was previously ignored because the M2 sampler read only `rgb`. The shader now reads `rgba`; alpha becomes authored local density and participates in optical depth, absorption, transmission, scattering, and layer weights. The density OFF/ON pair produced a real RGB change (MAE 2.2198, max 14) in the captured runtime evidence.
2. **Local optical direction** now uses `uResolution` texel offsets and finite differences over thickness, with a weak detail gradient. Radial direction is retained only as an explicit ablation. The captured radial/local pair remained nearly unchanged (MAE 0.0575, max 5), so this semantic correction is not visually proven and remains a blocker.
3. **Global pale flattening** was removed. The material uses wavelength-dependent absorption plus transmission/scattering balance, with an optional manual sRGB-linear-sRGB A/B. The linear pair differs from gamma (MAE 3.3902, max 20), but the visual advantage is still a human gate.
4. **Depth composition** is ordered rear transmission → internal scattering → front translucent contribution → formal shell. Each step is attenuated by accumulated alpha; the three source samples are no longer unconditionally added.
5. **Detail** now perturbs local optical direction, density/extinction, optical depth, and scattering. The captured Detail OFF/ON pair was too quiet (MAE 0.0192, max 13), so detail integration remains visually insufficient.
6. **Thickness** continues to drive transmission, absorption, and refraction. It does not generate a material rim; the formal outer film remains the shell authority.
