# K2 动态水球人工裁决规则

这套规则用于后续每一轮视觉审查，目标是让裁决只围绕用户能直接看到的结果，不要求用户理解 shader、field、endpoint 或 RGB 指标。

## 固定顺序

1. **球体完整吗？**
   - 只看“完整动态水球”展示。
   - 检查顶部、左右边缘、左上角和右上角。
   - 不能有缺口、断层、变形或多余叠层。

2. **播放时只动里面吗？**
   - 只看“内部变化水球”展示。
   - 点击展示框内的“自动播放”，观察几秒。
   - 外轮廓、边缘高光和核心位置应保持稳定，只有内部水纹和光影变化。

3. **它仍然像水吗？**
   - 只看“不同背景下的完整水球”展示。
   - 切换浅色、深色、分屏和棋盘背景。
   - 仍应是轻、湿、透明的水球，不能变成灰蓝实心球、雾球或塑料球。

## 答案和裁决

每题只允许三个答案：`是`、`否`、`看不出来`。

- 三题都是“是” → `PASS_REVIEW`，可以继续下一步。
- 任意一题是“否” → `REVISE_VISUAL`，先修正指出的问题。
- 任意一题是“看不出来” → `HOLD`，先暂停，补充更清楚的展示或说明。

最终文本必须包含：三题答案、最终裁决和备注。自动 GPU 检查只做辅助证据，不能替代人工材质判断。
